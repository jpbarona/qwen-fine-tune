# MLflow Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the custom React dashboard with MLflow, keeping every field the dashboard shows today and deleting the React code.

**Architecture:** The run folder stays the record. A mirror in the training process pushes metrics, tags and logged tables into a local MLflow store at each step. A sampler thread writes GPU rows to `gpu.jsonl` and to a nested MLflow child run. The existing read layer moves into a plain module so the live mirror and an importer share it.

**Tech Stack:** Python 3.12, MLflow 3.18.0, SQLite backend store, pytest.

**Spec:** `/home/opencode/Work/rl-grpo/docs/superpowers/specs/2026-11-23-mlflow-design.md`

## Global Constraints

- MLflow version is pinned exactly to `mlflow==3.18.0`.
- Backend store is `sqlite:///<runs-root>/mlflow.db`. Artifacts go to `<runs-root>/mlartifacts`.
- Experiment name is `rlvr`. Run name is `<arm>-<timestamp>`. The GPU child run is named `<arm>-<timestamp>-gpu`.
- The GPU sampler interval is one second, from `[mlflow] gpu_sample_seconds`, default `1.0`.
- The run folder is the record. `metrics.jsonl`, `labels.jsonl`, `eval.json` and `gpu.jsonl` are written before any MLflow call.
- A mirror failure never stops training. It writes `mlflow-errors.log` in the run folder.
- The run folder gains exactly two files: `gpu.jsonl` and `mlflow.json`.
- Metric names use letters, digits, `_`, `-`, `.` and `/`. Metric values are floats. Nulls are skipped.
- No React, no npm, no custom HTTP server in the final state.
- Tests run CPU only, with no network, on a temporary SQLite store.
- Every commit uses the repository author already configured. Do not change it.

## Review Focus

- A run with a null in a metric row. MLflow must skip the null, not write `NaN`.
- MLflow unavailable or the store locked. Training must finish and the JSONL must be complete.
- A resumed run. MLflow must not hold duplicate points past the last checkpoint.
- A crashed run. It must not stay `RUNNING` forever.
- A run folder with no `gpu.jsonl`, from an old run. The importer must not fail.
